 🚀 Weather App

A simple and responsive web project built using **HTML, CSS, and Basic JavaScript** with **API Fetching** functionality. 🌐✨

 ✨ Features

* 🎨 Clean & responsive UI
* ⚡ Basic JavaScript functionality
* 🌐 Fetches data from an external API
* 📱 Mobile-friendly design
* 🔄 Dynamic data display

 🛠️ Technologies Used

* 🧱 **HTML5**
* 🎨 **CSS3**
* ⚡ **JavaScript**
* 🌐 **Fetch API**

 📸 Preview

 🚀 How to Run

1. 📥 Clone or download the repository.
2. 📂 Open the project folder.
3. 🌐 Open `weatherapp.html` in your browser.
4. 🎉 Enjoy the project!
